    Data Cleaning & Text Parsing

    The source spreadsheet stores most quantitative information as free-text lab notes inside single cells. This pipeline (re-run on every upload and every watched-file change) converts that text into analyzable numeric and categorical fields, and never invents a value it cannot parse.

    1 · Raw cell

    Multi-line free text per field (Km, pH, temperature, donor/acceptor/metal lists), source row preserved.

    →
    2 · Validation

    Required columns, S. No. and Origin sanity-checked before anything is parsed.

    →
    3 · Controlled-vocabulary explosion

    Donor/metal lists split on newline + comma against a fixed token whitelist; free text is kept as a note, never fabricated as a substrate.

    →
    4 · Numeric extraction

    Km/pH/temperature parsed with unit conversion to µM and a standalone-number matcher that ignores digits glued to letters.

    →
    5 · Plausibility correction

    pH outside 0–14 swapped with an in-range temperature value when both sides become plausible; logged, never silent.

    →
    6 · Staged commit

    Only committed as the active dataset if the whole file validates; otherwise the last valid version is preserved.
